# snake
To compile:

`g++ snake.cc -lcurses -o snake`

To play the game:

`./snake`

To replay Xenia's best game:

`./snake snake.hist`



## typing

To compile:

`g++ typing.cc -lcurses -o typing`

To practice:

`./typing lessons/lesson1.txt`

The lessons start on the home row and add one row at a time.
The keyboard on screen inverts the key you press; the practice
text advances only when you type the right letter, and beeps
when you don't. ESC quits.
